# 模型设计说明

本项目对应电工杯 B 题“嵌入式社区养老服务站的建设与优化问题”。代码采用完整规划版实现，不再使用上一版的快速预筛选或局部重优化。

## 问题一：未来五年老人数量与服务需求量预测

采用多状态 Markov 模型预测自理、半失能、失能三类老人数量。模型显式纳入自然死亡率、新增老年人比例和健康状态转移概率。第 5 年需求计算分为两步：先计算理论月需求，再按消费上限进行等比例削减，得到消费约束后的月需求。

## 问题二：服务站选址与规模优化

基础模型采用 CMCLP，即容量约束最大覆盖选址模型，并结合容量约束设施选址思想。完整求解过程为：

1. 枚举所有建设预算可行的站点位置与规模组合；
2. 对每个方案运行“老人满意度最大选择 + 拥挤效应”固定点迭代；
3. 计算覆盖率、平均满意度、最低满意度、距离满意度掉档损失、响应满意度掉档损失、价格满意度掉档损失、站点利用率和年度利润；
4. 按多目标评分选择最优方案。

其中，响应满意度不是外生常数，而是由站点利用率决定。老人选择行为反过来改变站点利用率，因此形成双层规划思想下的内生满意度固定点问题。

## 问题三：服务定价与政府补贴优化

在问题二确定的站点位置和规模基础上，采用临界点定价方法。对五类收费服务进行价格候选点全组合枚举，紧急救助按题设固定为公益免费。价格方案必须满足保本和利润率不超过 8% 的约束。在每个站点自主定价后，重新计算价格变化下的消费约束需求、价格满意度、响应满意度和政府补贴。

代码同时输出潜在需求释放指数，用于衡量原本因消费能力不足而被压缩的需求，在降价与补贴机制下被释放的比例。

## 问题四：灵敏度分析与方案比较

每个扰动情景均重新运行问题一、问题二和问题三。代码同时将基准方案放到扰动情景下重新评价，并计算后悔值、鲁棒性指数、站点稳定率和规模调整率。这样可以区分两类问题：

1. 扰动情景下重新优化后应采用什么方案；
2. 原基准方案在扰动情景下是否仍然稳定。

## 完整版与快速版差异

当前版本已恢复以下完整逻辑：

- 问题二全量枚举所有预算可行方案；
- 问题三使用五类收费服务临界价格全组合枚举；
- 问题四每个情景重新求解问题二和问题三；
- 满意度掉档损失拆分为距离、响应、价格和综合满意度四类。
